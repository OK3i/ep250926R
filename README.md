# NestJS + TypeORM + PostgreSQL

## Setup

1. Install Node.js 20+
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the project:
   ```bash
   npm run start:dev
   ```
4. Start Docker services:
   ```bash
   docker-compose up --build
   ```

## Environment

The project uses variables from the `.env` file.
